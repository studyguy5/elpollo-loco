Class: character

character()

character this class represents the main character in the game, which is controlled by the player. It extends the MovableObject class, which provides basic movement and animation functionality. The character class includes properties for different animations (walking, jumping, idle, hurt, dead), as well as methods for handling movement, collisions, and animations.
